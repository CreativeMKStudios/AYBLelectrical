# AYBL Electrical

Static site for AYBL Electrical, the Bedford firm also known as IN2 Electrical Ltd (company number 10161275).

The design is a dark page with gold type, a phone button, and a large wordmark. Pages cover home, about, services, projects, reviews, the towns they cover, and contact.

## Run it

```bash
npm install
npm run dev
```

`npm run build` writes the site to `dist/`.

The canonical URL is set to `https://ayblelectrical.co.uk` in `astro.config.mjs`. Change that before launch if the live domain is different.

## What is on the site

- Address, phone and map from the Google listing: 27 St Cuthbert’s Street, Bedford, MK40 3JG, 01234 862212.
- Hours the firm published: Monday to Friday 9am–5pm, Saturday 9am–1pm, Sunday closed. Google shows Tuesday as 9am–5pm.
- Google score of 4.6 from 18 reviews, with a selection of public Google and Bark reviews quoted on the reviews page.
- Twelve job photos from the firm’s own website gallery.
- Town pages for Bedford, Milton Keynes, Luton, Flitwick, Harpenden, Hitchin, Leighton Buzzard, Olney and Woburn Sands.
- Sitemap, robots.txt, canonical links, and local-business structured data. Review stars from Google are shown on the page and are not copied into rating markup.
